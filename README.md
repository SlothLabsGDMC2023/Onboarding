# SlothLab — Onboarding Guide

Welcome to the **SlothLab** onboarding guide! In this walkthrough, you will learn how to create structures using our **Box-Split Grammar** system and generate them in **Minecraft** with **Amulet**. Your creations will be integrated into our procedural generator to create a complete settlement for the annual [**Generative Design in Minecraft (GDMC) Competition**](https://gendesignmc.wikidot.com/).

Our system builds on the architectural concepts described in [**Instant Architecture in Minecraft using Box-Split Grammars**](https://slothlab.info/assets/pdf/eger2022fdg.pdf) by Markus Eger. While academic papers can seem intimidating, we recommend reading it to get a background on how our grammar system functions. Everything is implemented in **Python** using the libraries introduced in the paper. Prior programming experience is helpful, but not required to get started.
